Di akhir sesi, peserta mempraktikkan alur kerja dari menulis prompt, membuat aplikasi Student Task Planner, hingga commit dan push ke GitHub.

## Materi yang Disampaikan
- Prompt engineering: cara menyusun instruksi agar AI memberi jawaban yang tepat, relevan, dan layak pakai.
- Git dan GitHub: perbedaan keduanya, Git workflow, perintah dasar, dan cara menghubungkan repository lokal ke GitHub.
- Setup environment: instalasi Git, VS Code, dan SSH key untuk koneksi ke GitHub.
- Praktik: membuat aplikasi Student Task Planner dengan bantuan AI, lalu mengunggahnya ke GitHub.

## Rangkuman Materi

**Prompt engineering**

- Prompt adalah instruksi yang diberikan ke model AI. Semakin spesifik dan berkonteks, semakin baik hasilnya.
- Struktur prompt yang baik terdiri dari Role, Task, Context, dan Format.
- Manfaatnya: performa AI lebih baik, bias dan respons offensive berkurang, hasil lebih terkontrol dan mudah diprediksi.

**Git dan GitHub**

- Git adalah version control system yang bekerja secara lokal dan mencatat siapa, kapan, dan apa yang berubah.
- GitHub adalah platform web untuk menyimpan repository Git secara online dan berkolaborasi.
- Perubahan melewati tiga area: working directory → staging area → repository (.git).

## Poin Penting dan Pengetahuan Baru
- Prompt singkat seperti “Create student task planner” kurang efektif dibanding prompt yang menjelaskan tujuan, kebutuhan, batasan, dan format hasil.
- Hasil AI perlu diverifikasi sebelum dianggap benar atau berfungsi.
- Git dan GitHub itu berbeda: Git untuk melacak perubahan di komputer, GitHub untuk menyimpan dan berbagi secara online.
- Alur kerja dasar yang paling sering dipakai adalah add → commit → push.
- SSH key membuat koneksi ke GitHub lebih praktis dan aman tanpa memasukkan kredensial berulang kali.
- Istilah penting: repository (tempat proyek dan riwayatnya), commit (catatan perubahan), branch (cabang pengembangan), pull request (permintaan menggabungkan perubahan).
